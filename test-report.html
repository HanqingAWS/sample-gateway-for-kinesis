◆ Architecture Overview

Replace AWS API Gateway ($3.50/M requests) with NLB + ECS Fargate running Nginx (OpenResty + Lua) and Vector, achieving the same query-string-to-Kinesis data pipeline at significantly lower cost with higher throughput.

Nginx + Lua (collect.lua)
• Receives GET requests on configurable paths (/guangdiantong, /toutiao, etc.)
• ngx.req.get_uri_args(0) extracts all query string parameters
• Builds flat JSON object with all values as strings
• Adds _path metadata for Vector routing
• POSTs JSON to Vector HTTP source via localhost (ECS awsvpc)
• Returns HTTP 200 immediately (async, non-blocking)
Vector (vector.toml)
• HTTP source on :8686, receives JSON from Nginx
• Route transform splits events by _path field
• Clean transforms remove metadata (path, source_type, timestamp)
• Kinesis sinks: batch 500 events / 5MB / 1s timeout
• Disk buffer on EBS gp3: block when full, survives container restart
• SigV4 auth via ECS Task Role (automatic credential chain)

▩ Disk Buffer & Disaster Recovery

Vector disk buffer persists events to EBS gp3 before sending to Kinesis. If Kinesis is unavailable, events accumulate on disk. When Kinesis recovers, Vector automatically replays buffered events.

Buffer behavior:
• when_full: block — backpressure to Nginx when disk full
• Data survives container restart (EBS ServiceManagedVolume)
• No TTL/expiry — events persist until delivered
• EBS attached/detached automatically by ECS
